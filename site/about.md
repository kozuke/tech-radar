# Tech Radar について

<p class="page-lead">技術系ブログ・公式リリース・チェンジログを毎日収集し、LLM で要約した日次ダイジェストとして配信しています。エンジニアが「今日の動き」を 5 分で把握するためのリーディング向けサイトです。</p>

<div class="info-grid">
  <section>
    <h2>収集する情報</h2>
    <p>AWS、AI 開発ツール、Google Workspace、主要 SDK のリリースなど、エンジニアが日々追いかけたいトピックを横断して取得します。</p>
  </section>
  <section>
    <h2>使い方</h2>
    <p>ホームの最新ダイジェストから読み始めるか、タグから関心領域を絞り込んでください。各記事から日次ダイジェストの全文を読めます。</p>
  </section>
  <section>
    <h2>仕組み</h2>
    <p>収集結果は Markdown と JSON で保存し、VitePress でビルドした静的サイトとして配信。GitHub Actions で毎日自動更新されます。</p>
  </section>
</div>
